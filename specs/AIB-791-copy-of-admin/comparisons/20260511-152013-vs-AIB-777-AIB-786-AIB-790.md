## Implementation Choices Analysis

### [Spec] Pre-flight and workflow share a single predicate (FR-025, SC-006)
| Ticket | Approach |
|--------|----------|
| AIB-791 | `app/lib/insights/predicate.ts` exports `countShippedClaudeTicketsSince` AND `listShippedClaudeJobsForWindow`, both calling the same private `queryShippedJobs` with effective-agent rule. |
| AIB-777 | `claudeEffectiveAgentJobWhere()` returns a shared Prisma where-fragment reused by both paths. |
| AIB-786 | `insights-scope.ts` exposes a single `buildInsightsScope` but pre-flight uses `previewInsightsScope` with a slightly different shape. |
| AIB-790 | Pre-flight uses `prisma.ticket.count({where: {stage:'SHIP', updatedAt:{gt:since}}})`; workflow uses the same `stage:'SHIP'` filter but enumerates jobs separately — divergence possible on revoked SHIP transitions. |

**Best**: AIB-791 — Strongest "by construction" guarantee.

### [Spec] Sandboxed iframe rendering (D-11)
| Ticket | Approach |
|--------|----------|
| AIB-791 | `<iframe sandbox="allow-scripts" src={/api/.../html} />` — exactly the spec |
| AIB-777 | `<iframe sandbox="allow-scripts" src={...} referrerPolicy="no-referrer" />` — exactly the spec |
| AIB-786 | Separate URL endpoint with sandboxed iframe |
| AIB-790 | `<iframe sandbox="" srcDoc={html} />` — **exact forbidden defect from the spec's "lessons from prior attempts"** |

**Best**: AIB-791/AIB-777 — AIB-790 reproduces the bug the spec was written to prevent.

### [Spec] Unauthorized response shape (D-3)
| Ticket | Approach |
|--------|----------|
| AIB-791 | `new Response(null, {status:404})` + `parity-404.test.ts` asserts byte equality vs baseline |
| AIB-777 | `new NextResponse(null, {status:404})` + dedicated `response-parity.test.ts` |
| AIB-786 | `NextResponse.json({error:'Not found'}, {status:404})` — leaks existence via JSON body |
| AIB-790 | `NextResponse.json({error:'Not found'}, {status:404})` — same leak |

**Best**: AIB-791/AIB-777.

### Decision Point: Background execution model
| Ticket | Approach | Constitution | Trade-off |
|--------|----------|--------------|-----------|
| AIB-791 | Workflow dispatch (`insights-analyze.yml`) + Job row | Yes | Mirrors all other long-running work |
| AIB-777 | Workflow dispatch (`insights-analyze.yml`) + Job row | Yes | Same |
| AIB-786 | Workflow dispatch | Yes | Same |
| AIB-790 | In-process `executeInsightsAnalysis(run.id).catch()` fire-and-forget | No | Crashes lose runs; no centralized capture |

**Best**: AIB-791/AIB-777/AIB-786 — AIB-790 violates D-4.
