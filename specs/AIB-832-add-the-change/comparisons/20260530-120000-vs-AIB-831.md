### Decision Point: Agent registry abstraction
| Ticket | Approach | Trade-offs |
|--------|----------|------------|
| AIB-832 | New `lib/models/agent-models.ts` with `AGENT_MODEL_METADATA`, `getAgentModelMetadata`, `isConfigurableAgent`, `isKnownModelId`. Resolver, schema, UI and API all consume the registry. | Single source of truth; adding a 3rd agent = one entry. UI lost the `isClaude` boolean. |
| AIB-831 | Inline `AGENT_MODEL_CONFIG` map inside `model-resolution.ts`; UI and schema still branch with `isClaude`/`isCodex` ternaries (`isCodex ? CODEX_MODEL_LABELS : CLAUDE_MODEL_LABELS`). | More duplication; adding a 3rd agent means touching 4+ files. |

**Best**: AIB-832 — cleaner, more extensible, follows the project's helper-module pattern.

### Decision Point: GitHub workflow dispatch routing
| Ticket | Approach |
|--------|----------|
| AIB-832 | Updates `speckit.yml`, `quick-impl.yml`, `verify.yml`, `inbox-analysis.yml` to set `ANTHROPIC_MODEL` when `inputs.agent == 'CLAUDE'` and `CODEX_MODEL` when `inputs.agent == 'CODEX'`, each with its own fallback. |
| AIB-831 | No workflow YAML changes — a Codex job dispatched from the UI would still flow into `ANTHROPIC_MODEL`. |

### Decision Point: Schema validation

## Ranking & Recommendation

### 1. AIB-832 — Best (91%)
**Why it wins**:
- Delivers **both** halves of the ticket: Opus 4.8 *and* full Codex per-stage selection with variants.
- `lib/models/agent-models.ts` registry removes per-agent branching across resolver, schema, UI, and API.
- Updates all four GitHub workflow YAMLs so Codex model selections actually reach the runner.
- Test coverage spans the new registry, the resolver for Codex, both UI components, and Codex smart-defaults.

### 2. AIB-831 — (62%)
**Why it lost**:
- **Misses Claude Opus 4.8 entirely** — half the spec is undelivered.
- No GitHub workflow YAML changes — the UI lets users pick a Codex model that the dispatch layer can't route.
- Smaller Codex catalogue (4 IDs, no mini/codex variants per generation).
- UI/schema still carry duplicated `isClaude`/`isCodex` branching.
