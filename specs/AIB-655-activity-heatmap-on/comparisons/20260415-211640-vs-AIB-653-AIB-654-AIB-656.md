## Implementation Choices Analysis

### [Spec] Violet gradient intensity
| Ticket | Approach |
|--------|----------|
| AIB-655 | Static Tailwind `bg-violet-*` classes with ratio-based levels |
| AIB-653 | Emerald palette (`bg-emerald-*`) with quantile-based levels |
| AIB-654 | Custom CSS classes (`heatmap-level-*`) using `--primary-violet` CSS variable; quartile intensity |
| AIB-656 | Static Tailwind `bg-violet-*` + `bg-fuchsia-*` with max-ratio intensity |

**Best**: AIB-655/656 - Use violet palette matching spec. AIB-653 uses wrong color (emerald). AIB-654 uses dynamic class construction (`heatmap-level-${level}`) which violates CLAUDE.md rules on dynamic Tailwind class names.

### [Spec] Tooltip with cost/job details
| Ticket | Approach |
|--------|----------|
| AIB-655 | Custom fixed-position tooltip (mouse position-based) with mobile tap dismiss overlay |
| AIB-653 | shadcn Popover-based details panel |
| AIB-654 | shadcn TooltipProvider/Tooltip (proper Radix primitive) |
| AIB-656 | shadcn Tooltip (desktop hover) + Popover (mobile tap) combined pattern |

**Best**: AIB-656 - Dual tooltip strategy handles both desktop and mobile correctly using shadcn primitives per constitution.
