## Implementation Choices Analysis

### [Spec] Color system for intensity scale (FR-009)
| Ticket | Approach |
|--------|----------|
| AIB-672 | `aurora-heatmap-cell-*` utility classes in globals.css |
| AIB-669 | Aurora gradient via tokenized utility classes |
| AIB-670 | Tailwind palette + CSS var composition |
| AIB-671 | **Hardcoded `bg-[hsl(var(--primary-violet)/0.18)]`** inline |
| AIB-673 | Token-based helper `intensityClass` |

**Best**: AIB-672, AIB-669, AIB-673 — follow CLAUDE.md rule on no hardcoded colors.

### Decision Point 1: Component decomposition
| Ticket | Approach | Constitution |
|--------|----------|--------------|
| AIB-672 | Single 420-line monolith | Partial |
| AIB-669 | Split into ActivityHeatmap + HeatmapGrid + HeatmapFilters + types | Yes |
| AIB-670 | Single 344-line monolith | Partial |
| AIB-671 | Single 363-line monolith | Partial |
| AIB-673 | Split into ProjectsActivityHeatmap + HeatmapGrid | Yes |

**Best**: AIB-669 — best aligns with Component-Driven principle.

### Decision Point 2: Cost-null handling precision (FR-020)
| Ticket | Approach |
|--------|----------|
| AIB-672 | Tracks `nullCostJobCount` for labeled partial-cost days |
| AIB-669 | `null` sentinel; addCost guards against null |
| AIB-670 | `null` sentinel, avoids `$0` fallback |
| AIB-671 | `costSeen` flag with rounded sum |
| AIB-673 | Guards `if (job.costUsd != null)` before sum |

**Best**: AIB-672 — most precise; explicitly surfaces partial-cost days.

### Decision Point 3: Mobile tap dismissal (FR-021)
| Ticket | Approach |
|--------|----------|
| AIB-672 | Tooltip dismiss via outside-click |
| AIB-669 | Radix Tooltip, hover-only wired |

| AIB-671 | Hover + tap |
| AIB-673 | **Popover** component — native open/close, best mobile UX |

**Best**: AIB-673 — Popover gives proper tap-outside-dismisses behavior out of the box.
