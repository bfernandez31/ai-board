## Implementation Choices Analysis

### [Spec] FR-003 Violet aurora gradient theming
| Ticket | Approach |
|--------|----------|
| AIB-702 | `aurora-cell-0..3` CSS classes backed by `--ctp-sapphire/mauve/pink` design tokens |
| AIB-690 | `aurora-heatmap-bucket-0..4` classes using project violet tokens |
| AIB-692 | Intensity map with `violet-900` + `ctp-surface0` — semantic but not aurora gradient |
| AIB-701 | Hardcoded Tailwind `bg-violet-200..500` switch — palette classes (allowed), no aurora |

**Best**: AIB-702 / AIB-690 — true aurora theme per spec intent.

### [Spec] FR-013 Mobile tap tooltip
| Ticket | Approach |
|--------|----------|
| AIB-702 | Radix TooltipProvider (hover + tap) with `delayDuration=0` |
| AIB-690 | `matchMedia('(hover: none)')` → Popover on touch, Tooltip on desktop |
| AIB-692 | shadcn Tooltip, no explicit touch handling |
| AIB-701 | onMouseEnter + onFocus + onClick, `pointerdown` outside-dismiss |

**Best**: AIB-690 — most deliberate responsive UX. AIB-702 + AIB-701 solid; AIB-692 weakest.

### Decision Point: Data fetching strategy
| Ticket | Approach | Constitution | Trade-offs |
|--------|----------|--------------|------------|
| AIB-702 | Pure SSR, Suspense boundary, URL-driven re-render | Yes | Simplest, matches FR-011 natively, no client cache |
| AIB-690 | TanStack Query + initialData, 15s refetch | Yes | Fresh data, but aggressive polling for cold data |
| AIB-692 | TanStack Query + initialData, 60s refetch | Yes | Reasonable cadence, good hydration reuse |
| AIB-701 | TanStack Query + initialData, 15s refetch | Yes | Same polling concern, smart placeholderData |

**Best**: AIB-702 — SSR is the cleanest match for mostly-static aggregated activity; CLAUDE.md reserves polling for jobs/notifications, not heatmaps.

## Ranking & Recommendation

### 1. **AIB-702** — Best code (score: 91%)
**Why it wins**:
- Cleanest component decomposition (4 files, each <110 lines)
- Pure SSR pattern is the simplest answer to FR-011's "no loading flash" requirement
- Aurora theme via design tokens (FR-003) + no hardcoded hex
- Zod schema drives response typing; no `any`
- E2E + integration + unit coverage
- Smallest footprint (1039 lines) delivers full feature set
- Zero invasive edits to shared infra

### 2. **AIB-690** — (score: 85%)
**Why it lost**:
- Most sophisticated mobile UX and type system, but ~70% larger codebase than AIB-702
- Aggressive 15s polling is unnecessary for heatmap data
- 248-line main component mixes filter UI, legend, and error UI

### 3. **AIB-701** — (score: 81%)
**Why it lost**:
- Modifies `lib/db/users.ts` (+57/-18) — scope leak into shared auth code
- 539-line lib file and 335-line component less decomposed
- Uses `bg-violet-*` palette instead of aurora theme classes (FR-003 partial)
- Strongest test count (4 files) is a genuine plus

### 4. **AIB-692** — (score: 76%)
**Why it lost**:
- No explicit mobile tap handling (FR-013 partial)
- 299-line monolithic component
- Violet semantic classes but no aurora gradient (FR-003 partial)
