## Implementation Choices Analysis

### Decision Point 1: Database schema shape (typed columns vs JSON blob)
| Ticket | Approach | Trade-offs |
|--------|----------|------------|
| AIB-678 | 5 dedicated `VARCHAR(50)` columns per table (`specifyModel`, `planModel`, `implementModel`, `quickImplModel`, `verifyModel`) | Schema-enforced shape, indexable, cheap filtering, clearer Prisma types. Adding a 6th stage is a migration. |
| AIB-679 | Single `Json?` column (`claudeModels`, `claudeModelOverrides`) + runtime `sanitizeClaudeModelMap()` | Flexible for schema evolution, but loses DB-level validation, requires runtime sanitization on every read, no index-friendly queries. |

**Best**: AIB-678 — aligns with Constitution §V (Database Integrity) and Prisma-first typing.

### Decision Point 2: API endpoint granularity
| Ticket | Approach |
|--------|----------|
| AIB-678 | Dedicated endpoints: `POST …/model-config/apply-smart-defaults`, `PATCH/DELETE …/tickets/[id]/model-config`. Clear separation of concerns. |
| AIB-679 | Reuses existing `PATCH …/tickets/[id]` + `PATCH …/projects/[id]` with extended payload. Fewer routes, more overloading. |

**Best**: AIB-678 — dedicated endpoint is required to even deliver FR-008, which AIB-679 omits entirely.

### Decision Point 3: Library organization
| Ticket | Approach |
|--------|----------|
| AIB-678 | Split into `lib/models/claude-models.ts` (constants/whitelist) and `lib/workflows/model-resolution.ts` (resolution). Imports by concern. |
| AIB-679 | All 166 lines in one `lib/workflows/claude-models.ts` (constants, stages, descriptions, sanitize, resolve, overridden-keys helper). |

**Best**: AIB-678 — smaller, single-purpose modules are easier to test (see dedicated `model-resolution.test.ts`).

### Decision Point 4: Haiku model ID
| Ticket | ID used | Correctness |
|--------|---------|-------------|
| AIB-678 | `claude-haiku-4-5-20251001` | Matches Anthropic's canonical ID — works at dispatch. |
| AIB-679 | `claude-haiku-4-5` | Short alias — may not resolve against Anthropic API without an alias mapping. |

**Best**: AIB-678.
