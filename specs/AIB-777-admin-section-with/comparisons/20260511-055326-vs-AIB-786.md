## Implementation Choices Analysis

### [Spec] FR-011 — Run the genuine Claude Code `/insights` analyzer
| Ticket | Approach |
|--------|----------|
| AIB-777 | Workflow installs `@anthropic-ai/claude-code`, downloads raw native JSONL, then runs `claude /insights --input-dir /tmp/sessions --output-html /tmp/report.html --period-start ... --period-end ...` |
| AIB-786 | Workflow concatenates JSONL into `/tmp/aggregated.jsonl`, then asks Claude with a free-text prompt: "Produce a single self-contained HTML document at $REPORT_OUTPUT". This is a re-implementation, not the genuine analyzer. |

**Best**: AIB-777 — directly satisfies FR-011 ("no re-implementation, no transformation").

### [Spec] FR-015 — Orphan-row timeout reconciliation
| Ticket | Approach |
|--------|----------|
| AIB-777 | `reconcileOrphanedInsightsReports()` flips any RUNNING row older than `INSIGHTS_RUN_TIMEOUT_MS` (default 60min) to FAILED; called on every list load and every trigger attempt (lazy reconciliation). |
| AIB-786 | No mechanism — a stuck RUNNING row blocks future triggers forever. |

**Best**: AIB-777 — FR-015 is non-negotiable.

### [Spec] FR-018 — Sandbox rendering
| Ticket | Approach |
|--------|----------|
| AIB-777 | Iframe `src=/api/admin/insights/reports/:id/html` with `sandbox="allow-scripts"` + server response headers `Content-Security-Policy: default-src 'self' 'unsafe-inline' data:; frame-ancestors 'none'`, `X-Frame-Options: DENY`. |
| AIB-786 | Iframe `srcDoc={html}` with `sandbox=""` — disables scripts AND same-origin. Safe, but means `/insights`-generated charts/interactivity are inert; the host page also loads the body inline, growing the React payload. |

**Best**: AIB-777 — keeps the analyzer's HTML functional while still isolated.

### Decision Point: State machine for status transitions
| Ticket | Approach | Trade-offs |
|--------|----------|------------|
| AIB-777 | `canTransition` table + atomic conditional `updateMany({ where: { id, status: 'RUNNING' } })` so lost races are no-ops. | Robust against double-callbacks. |
| AIB-786 | Plain `update()` with no guard. | A late workflow callback can flip a COMPLETED row back to RUNNING. |

**Best**: AIB-777.

### Decision Point: Component structure
| Ticket | Approach | Constitution II |
|--------|----------|-----------------|
| AIB-777 | Feature folder `app/components/admin/insights/` with 6 small focused components + 2 typed hooks. | Aligned |
| AIB-786 | Single 383-line `components/admin/insights-page-client.tsx` doing list + viewer + trigger inline. | Partial |

**Best**: AIB-777.

## Ranking & Recommendation

### 1. AIB-777 — score 92%
**Why it wins**:
- Calls the real `claude /insights` analyzer (FR-011)
- Ships orphan-row reconciliation (FR-015)
- Response-parity test enforces FR-003 byte-equivalence
- Correct effective-agent CLAUDE filter (FR-010, FR-025)
- Full test pyramid (E2E + integration + unit, 11 test files)
- Stronger isolation: separate-URL iframe + CSP headers + atomic state-machine transitions

### 2. AIB-786 — score 72%
**Why it lost**:
- Re-implements `/insights` with a free-text prompt instead of invoking the analyzer
- No timeout for orphaned RUNNING rows — a stuck row permanently blocks triggers
- 383-line monolithic client component violates Component-Driven principle
- Only 3 unit tests; no integration, no E2E, no 404-parity test
- `sandbox=""` neutralises scripts inside the report; charts/interactivity die
- Status PATCH does not gate on current status (race condition on duplicate callbacks)
