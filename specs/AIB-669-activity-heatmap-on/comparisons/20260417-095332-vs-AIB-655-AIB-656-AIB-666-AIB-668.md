## Implementation Choices Analysis

### [Spec] Server-side prefetch respects URL searchParams
| Ticket   | Approach                                                              |
|----------|-----------------------------------------------------------------------|
| AIB-669  | Server reads searchParams, prefetches with correct period/agent       |
| AIB-655  | Server prefetches with default `rolling`/`all`, client re-fetches     |
| AIB-656  | Server reads searchParams, prefetches correctly                       |
| AIB-666  | Server reads searchParams, prefetches correctly                       |
| AIB-668  | Server always calls with `{}`, client must re-fetch on every load     |

**Best**: AIB-669/AIB-656/AIB-666 — deep links hydrate without client roundtrip.

### [Spec] Timezone-correct daily aggregation (UTC)
| Ticket   | Approach                                                              |
|----------|-----------------------------------------------------------------------|
| AIB-669  | UTC-only date math throughout                                         |
| AIB-655  | Local `getFullYear()`/`getMonth()` — drifts by viewer timezone        |
| AIB-656  | UTC-safe; weeks built before shaping                                  |
| AIB-666  | UTC-safe                                                              |
| AIB-668  | `setHours()`/`endOfDay` use local TZ — bug risk                       |

**Best**: AIB-669/AIB-656/AIB-666.

### Decision Point 2: Intensity bucketing

## Ranking & Recommendation

### 1. **AIB-669 (source)** — Best code (score: **91%**)
**Why it wins**:
- Only branch that combines: clean 3-file decomposition, UTC-only date math, quartile intensity, strict Zod, single-pass aggregation, and searchParams-driven server prefetch.
- Constitution-aligned across all five evaluated principles.

### 2. **AIB-656** — score: **83%**
**Why it lost**: Bundles unrelated per-project activity-feed scope; mixed violet/fuchsia color palette; loose Zod schema validation. Strong tests though.

### 3. **AIB-666** — score: **76%**
**Why it lost**: No Zod validation; clunky `year-YYYY` URL format; extra DB round-trip per request; bundles scope-creep activity-feed files.

### 4. **AIB-668** — score: **74%**
**Why it lost**: Local-time date math (TZ bug); ignores server searchParams (breaks deep-link prefetch); component lives outside `components/projects/`; over-fetches jobs to count agents.

### 5. **AIB-655** — score: **73%**
**Why it lost**: 400-line monolith component; local-time dates; manual regex validation (no Zod); linear intensity skews low. Best integration test, but architecture is weakest.
